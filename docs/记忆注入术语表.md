# 记忆注入术语表

每个概念只有一个正式名。对话、代码注释、日志、文档都用这一个名字，旧叫法一律不再使用。

## 速查

| 概念 | 一句话 |
|---|---|
| 快照 | 天使之心交过来的这一轮对话记录 |
| 上下文 | 本次请求真正发给模型的那段历史消息 |
| 长期库 | 全部记忆的存放处 |
| 检索 | 拿一句话去长期库找相关记忆 |
| 短期记忆 | 本次会话记住了哪些记忆、各自跟着哪条消息 |
| 记忆条目 | 短期记忆里的一条记录 |
| 绑定消息 | 把这条记忆带进短期记忆的那条用户消息 |
| 进入 | 记忆第一次被带进短期记忆的那一刻 |
| 进入侧去重 | 同一条记忆再次被召回时直接跳过，且不改绑 |
| 在场消息 | 本次请求里还存在的用户消息 |
| 离场 | 绑定消息已不在上下文，记忆随之离开 |
| 离场反思 | 记忆离开时连同那条消息一起交给小模型复盘 |
| 轮次反思 | 每轮对话结束后照常跑的那次复盘 |
| 注入 | 把记忆写成文字塞进这次请求 |
| 挂载点 | 注入块落地的物理位置 |
| 注入块 | 被 `<system_context>` 包起来的那段内容 |
| 尾部对齐配对 | 快照与上下文各自从最后一条往前一对一配 |

## 一、数据来源

### 快照

天使之心交过来的这一轮对话记录，本进程只读不改。

落点：`chat_records`
旧叫法（不再使用）：账本、天使之心账本、整份记录

### 上下文

本次请求真正发给模型的那段历史消息。快照可能比它长，也可能比它短，两者不是一回事。

落点：`request.contexts`
旧叫法（不再使用）：对话历史、请求上下文

### 长期库

全部记忆的存放处，由 p-memory 承载。短期记忆里的内容来自这里，但进入之后不再回查。

落点：`pmemory/` 封装层
旧叫法（不再使用）：库、数据库

### 检索

拿一句话去长期库找相关记忆。一次请求只在记忆进入短期记忆之前做一次，注入时不再检索。

落点：`DeepMindRetrievalService`
旧叫法（不再使用）：召回

## 二、短期记忆

### 短期记忆

本次会话记住了哪些记忆、各自跟着哪条消息。规模由请求里还有多少条消息决定，没有容量上限。

落点：`SessionMemory` / `SessionMemoryManager`
旧叫法（不再使用）：短期仓、会话工作记忆缓存、工作记忆缓存

### 记忆条目

短期记忆里的一条记录，装着三样东西：记忆本体、绑定消息 ID、绑定消息正文。

落点：`MemoryItem`
旧叫法（不再使用）：引用、失效引用、记忆项

### 绑定消息

把这条记忆带进短期记忆的那条用户消息。绑定在进入时定下，之后不再改。

落点：`bound_message_id` / `bound_message_text`
旧叫法（不再使用）：带入这条记忆的消息、目标消息

### 进入

记忆第一次被带进短期记忆的那一刻。同一条记忆只进入一次。

落点：`SessionMemory.add_memories`
旧叫法（不再使用）：入场、入仓

### 进入侧去重

同一条记忆再次被召回时直接跳过，且不刷新绑定。第一条消息带进来的记忆，后面的消息再怎么召回都不管。

落点：`SessionMemory._add_memory_item`
旧叫法（不再使用）：首发单次绑定、跨消息去重

### 在场消息

本次请求里还存在的用户消息。有快照时取快照里的用户消息，没有快照时只剩当前这一条。

落点：`DeepMind._alive_message_ids`
旧叫法（不再使用）：存活消息、真实存在的消息、未丢失的消息

### 离场

绑定消息已不在上下文，记忆随之离开短期记忆。说的是消息不在了，不是时间到了。

落点：`prune_absent_messages` / `prune_absent_messages_from_session`
旧叫法（不再使用）：过期、失效、消息走了

## 三、反思

### 离场反思

记忆离场时，把它的正文和绑定消息一起交给小模型复盘。这时没有对应回答，回答一栏留空。

落点：`DeepMind._reflect_departed_memories`
旧叫法（不再使用）：离场送审、反思过期记忆、送去反思

### 轮次反思

每轮对话结束后照常跑的那次复盘，账目按实际挂进请求的那批记忆写。

落点：`after_message_sent` → `memory_runtime.feedback`
旧叫法（不再使用）：常规反思、每轮反思、反馈

## 四、注入

### 注入

把记忆写成文字塞进这次请求。注入不检索，只按短期记忆里的绑定关系挂位置。

落点：`DeepMindInjectionService`
旧叫法（不再使用）：挂载、喂给主意识

### 挂载点

注入块落地的物理位置，只有两种：当前消息的附加内容、历史消息后面。没有快照时只挂当前消息，上下文一行不碰。

落点：`_attach_current_block` / `attach_history_blocks`
旧叫法（不再使用）：附加内容、extra_user_content_parts

### 注入块

被 `<system_context>` 包起来的那段内容，分当前块和历史块。当前块装仪表盘、画像、笔记与记忆，历史块只装记忆。

落点：`_render_block`
旧叫法（不再使用）：上下文块、系统上下文块、块

### 尾部对齐配对

快照的用户消息与上下文的用户消息各自成列，从最后一条往前一对一配。快照多出来的那几条视为已被截断，直接丢弃；配上的再核对内容，对不上也丢弃。

落点：`attach_history_blocks`
旧叫法（不再使用）：尾部比对、从尾部往前配对

## 有待处理的命名

`chained_recall` 这个名字指的是四步串联的检索机制，那套机制在 p-memory 接管检索时已经不存在了。现在它只是一次普通检索，参数 `per_type_limit` 也随之失去作用。名字暂时保留，处理方式待定。

## 使用约定

- 说「短期记忆」不说「短期仓」；说「离场」不说「过期」。
- 两套反思必须叫全名，不简称「反思」。
- 遇到没收录的词，先确认它是不是已经在别处有了正式名，再决定要不要新增。
